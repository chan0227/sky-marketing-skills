# Korean Content Marketing Skill

> **2026 한국 콘텐츠 소비 현황**: 네이버 블로그 MAU 4천만+, 인스타 한국 사용자 2500만+, 유튜브 일평균 시청 70분+
> 한국은 채널별 **사용자 페르소나·콘텐츠 톤·길이 기준이 완전히 다릅니다**.

## 🎯 언제 이 스킬을 쓰나요?

- "블로그 글 시리즈 기획해줘"
- "인스타 콘텐츠 캘린더 만들어줘"
- "브런치 에세이 톤으로 써줘"
- "카카오 채널 메시지 시리즈"
- "한국형 콘텐츠 마케팅 전략"
- "콘텐츠 시리즈 30개 기획"
- "유튜브 쇼츠 + 블로그 연계"

## 🔑 채널별 페르소나·톤 매트릭스

각 채널은 사용자가 완전히 다릅니다. 같은 콘텐츠를 4개 채널에 그대로 올리면 다 실패합니다.

| 채널 | 주 사용자 | 톤 | 글 길이 | 핵심 가치 |
|---|---|---|---|---|
| **네이버 블로그** | 30~50대 정보 탐색자 | 친근·생활밀착 | 1500~3000자 | 실용 정보, 후기 |
| **티스토리** | 20~40대 IT/전문 관심 | 정보·전문가 | 2000~5000자 | 깊이 있는 분석 |
| **브런치** | 25~45대 감성·지적 | 에세이·문학 | 2000~4000자 | 사유, 감성 |
| **인스타 피드** | 20~40대 비주얼 중심 | 트렌디·간결 | 100~300자 | 시각 임팩트 |
| **인스타 릴스** | 10~30대 짧은 영상 | 빠르고 후킹 | 영상 15~60초 | 첫 3초 임팩트 |
| **카카오 채널** | 충성 고객 (관계형) | 친근·실용 | 200~500자 | 즉시 행동 유도 |
| **유튜브 쇼츠** | 10~40대 전 연령 | 후킹·고밀도 | 영상 60초 이내 | 첫 5초 + 반복 시청 |
| **유튜브 롱폼** | 정보·교육 탐색자 | 정보·전문가 | 영상 8~15분 | 깊이 + 체류시간 |

## 🛠️ 작업 프로세스

### Step 1: 마케팅 목표 → 채널 선택

사용자에게 질문:
```
"콘텐츠 마케팅의 1차 목표는?"
1. 인지도 확보 (브랜드 노출) → 인스타 릴스 + 유튜브 쇼츠
2. 정보·신뢰 구축 → 네이버 블로그 + 티스토리
3. 감성·브랜드 팬덤 → 브런치 + 인스타
4. 전환·매출 → 네이버 블로그 + 카카오 채널
5. 교육·전문성 → 티스토리 + 유튜브 롱폼
```

### Step 2: 콘텐츠 필러(Pillar) 설계

각 비즈니스마다 **3~5개 콘텐츠 필러**를 정합니다:

예시 (Sky AI의 경우):
- **필러 1**: AI 도구 활용법 (실습형) — 40%
- **필러 2**: AI 교육 인사이트 (사고형) — 25%
- **필러 3**: 고객사 도입 사례 (사례형) — 20%
- **필러 4**: 강사·회사 일상 (인간미) — 10%
- **필러 5**: 시장·정책 동향 (분석형) — 5%

### Step 3: 콘텐츠 시리즈화

단발성 글은 채널 자산이 되지 않습니다. **시리즈로 묶어야** 알고리즘과 사용자 모두에게 가산점.

**시리즈 구조 예시**:
```
[Claude 100% 활용 시리즈]
- 1편: Claude로 회의록 자동화하기
- 2편: Claude로 제안서 초안 만들기
- 3편: Claude로 데이터 분석하기
- 4편: Claude로 이메일 답장하기
- 5편: Claude 스킬 시스템 시작하기
```

10편 이상 시리즈가 누적되면 검색 노출과 구독 전환이 급격히 오릅니다.

### Step 4: 채널별 적응(Adaptation)

같은 메시지를 채널마다 다르게 가공합니다.

**예시 메시지**: "AI 교육은 도구 사용법이 아니라 사고방식의 전환"

```
[네이버 블로그] 2000자
→ 도입: 강의 현장 에피소드 (실제 경험담)
→ 본문: 3가지 사례로 도구 사용법의 한계 설명
→ 결론: 사고방식 전환의 구체적 5단계
→ CTA: 무료 자가 진단 도구 다운로드

[티스토리] 3000자
→ 도입: 데이터·통계로 시작 (AI 도입 실패율 65%)
→ 본문: 학술적 분석 + 구체적 방법론
→ 결론: 프레임워크 제시
→ CTA: 심층 컨설팅 문의

[브런치] 1500자
→ 에세이 톤: "AI를 배운다는 것의 의미"
→ 개인적 성찰 + 비유 + 문학적 표현
→ CTA: 없음 (브런치는 직접 영업 금기)

[인스타 피드] 캐러셀 8장
→ 1장: 후킹 ("AI 교육 받아도 안 늘던 이유")
→ 2-7장: 각 슬라이드 1개 인사이트
→ 8장: 요약 + 저장 유도

[릴스] 영상 30초
→ 0-3초: "AI 교육비 천만원 쓰고도 안 늘었다면"
→ 4-25초: 3가지 이유 빠르게 (자막 필수)
→ 26-30초: 솔루션 한 줄 + 팔로우 유도

[카카오 채널] 메시지 300자
→ 친근한 인사 → 핵심 1줄 → 더보기 링크
```

## ✍️ 한국형 카피라이팅 공식

### 후킹 헤드라인 5종 (한국 시장 검증됨)

1. **숫자 + 비교형**: "월 300만 원 버는 N잡러 5가지 공통점"
2. **부정 어휘 + 호기심**: "AI 교육비 천만 원 쓰고 망한 이유"
3. **질문 + 공감**: "혹시 ChatGPT만 쓰고 계신가요?"
4. **시간 + 약속**: "30분 만에 끝내는 보고서 자동화"
5. **상식 깨기**: "검색은 더 이상 SEO가 아닙니다"

### CTA 한국형 동사

- ✅ 효과 좋음: "확인하기", "알아보기", "받아가기", "신청하기"
- ❌ 영문 직역: "지금 시작", "다운로드", "구독"(만 단독으로는 약함)
