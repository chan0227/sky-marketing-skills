# Korea B2B/B2G Sales Enablement Skill

> **한국 B2G 시장 규모 (2026 기준)**: 연간 공공조달 시장 약 200조 원 / 정부 AI·디지털 사업만 연 5조 원 이상
> 한국 공공·B2B 영업은 미국식과 **문화·절차·문서 양식이 근본적으로 다릅니다**.

## 🎯 언제 이 스킬을 쓰나요?

다음 요청에서 즉시 이 스킬을 활성화합니다:

- "정부 사업 제안서 써줘"
- "공공기관 영업 자료 만들어줘"
- "지자체 RFP 응답"
- "나라장터 입찰 준비"
- "관공서 ○○ 사업 제안"
- "공공기관 미팅용 회사 소개서"
- "한국 대기업 영업 자료"
- "○○부/청 사업 응모"

## 🔑 핵심 원칙

### 1. 한국 공공·대기업 영업은 "관계 + 신뢰 + 절차"

미국식 영업은 "가치 제안 → 데모 → 가격 → 계약" 순서이지만, 한국 B2G/B2B는:

```
사전 정보 수집 → 관계 형성 → 실무자 검토 → 의사결정자 보고 → 절차 진행
   (수개월)     (수개월)    (수주)       (수주)         (수주~수개월)
```

**모든 영업 자료는 이 단계별로 다르게 설계되어야** 합니다.

### 2. 문서 양식이 곧 신뢰도

한국 공공기관은 **양식·형식**을 매우 중요시합니다. 내용이 좋아도 양식이 어긋나면 검토 대상에서 제외됩니다.

필수 양식 요소:
- **공식 한글 명칭** (영문 + 한글 병기 시 한글 우선)
- **연/월/일 표기** (2026. 6. 15. — 점 사이 공백 한 칸)
- **결재선 가시화** (담당 → 팀장 → 부서장 → 본부장)
- **단위 표기 통일** (백만 원 / 천만 원 / 억 원 중 하나로 통일)
- **출처 명시** (정부 통계, KOSIS, e-나라지표 등)

### 3. "정량 + 정성 + 사례" 3종 세트

한국 의사결정자는 다음 세 가지를 모두 요구합니다:
- **정량 근거**: 구체적 숫자 (시장 규모, ROI, 절감액)
- **정성 가치**: 사회적 가치, 정책 부합도, 지역 기여
- **유사 사례**: 타 기관·기업의 도입 성공 사례

이 셋 중 하나라도 빠지면 보고 단계에서 막힙니다.

## 🛠️ 작업 프로세스

### Step 1: 영업 단계 진단

사용자에게 먼저 질문:

```
"현재 영업 단계가 다음 중 어디입니까?"
1. 잠재 고객 발굴 (Cold) - 첫 접촉 자료
2. 관계 형성 단계 (Warm) - 회사 소개 + 사례
3. 실무자 검토 (Hot) - 구체적 제안서
4. 의사결정 보고 (Decision) - 임원 보고용 요약
5. 입찰·RFP 대응 (Bidding) - 공식 제안서
```

각 단계마다 작성하는 문서가 완전히 다릅니다.

### Step 2: 단계별 산출물 가이드

#### 단계 1: Cold (첫 접촉)
**산출물**: 1장짜리 회사 소개 + 가치 제안서

```markdown
# [회사명] / [한 줄 가치 제안]

## 우리는 누구인가
- 한 문장 회사 정체성
- 핵심 실적 3가지 (정량)

## 무엇을 도와드릴 수 있나
- 귀 기관의 [구체적 과제] 해결
- 유사 기관 [○○청] 도입 사례

## 다음 단계 제안
- 30분 인사이트 미팅 제안
- 담당자: [이름/직책/연락처]
```

#### 단계 2: Warm (관계 형성)
**산출물**: 8~12장 회사 소개서

필수 구성:
1. 표지 (기관명 + 일자 + 제출자)
2. 회사 개요 (설립일, 대표, 매출, 인원)
3. 핵심 사업 영역 (시각화)
4. 주요 고객사 (특히 공공 사례 강조)
5. 유사 기관 도입 사례 (3건 이상)
6. 차별화 포인트 (3가지)
7. 우리의 약속 (책임·SLA)
8. 제안 다음 단계

#### 단계 3: Hot (실무자 검토)
**산출물**: 20~30장 사업 제안서 (`gov-proposal` 스킬 연계)

추가 필수 항목:
- 사업 추진 일정 (간트차트)
- 인력 투입 계획 (전담 인력 명시)
- 기대 효과 (정량 + 정성)
- 위험 관리 방안
- 비용 견적 (옵션별)

#### 단계 4: Decision (임원 보고)
**산출물**: 3~5장 임원 요약 (Executive Summary)

원칙: **임원은 표지 + 1페이지만 본다** 가정

```
1페이지: 핵심 메시지 3개 + 의사결정 요청 사항
2페이지: 시장 상황 + 우리 솔루션 (1장 인포그래픽)
3페이지: 도입 효과 (숫자 중심)
4페이지: 일정 + 예산
5페이지: 다음 단계 + 의사결정 항목
```

#### 단계 5: Bidding (공식 입찰)
**산출물**: RFP 응답 제안서 (`gov-proposal` 스킬 사용)

RFP 응답 시 절대 원칙:
- ✅ RFP의 **목차 순서를 그대로** 따른다
- ✅ RFP의 **평가 항목별 배점 비중대로** 분량 배분
- ✅ "필수 요구사항"은 표로 일대일 매핑
- ❌ 멋있어 보이려고 RFP에 없는 항목 추가 금지

## 📋 한국 공공 영업 문서 양식 규칙

### 표지 양식 (필수)
```
┌─────────────────────────────────────┐
│        [발주기관 정확한 명칭]        │
│                                     │
│         ○○○○ 사업 제안서          │
│                                     │
│         2026년 ○월 ○일              │
│                                     │
│        제안업체: ○○○○             │
│        대표자: ○○○ (인)            │
└─────────────────────────────────────┘
```

### 일자 표기
- ✅ 올바른: `2026. 6. 15.` (점 뒤 공백, 마지막 점)
- ❌ 잘못된: `2026.06.15` / `2026-06-15` / `2026년 6월 15일` (공문 외)

### 금액 표기
- ✅ `금 1억 5천만 원 정 (₩150,000,000)` (한글 + 숫자 병기)
- ✅ 표 내부는 `천 원` 또는 `백만 원` 단위 통일
- ❌ 단위 혼용 (어떤 줄은 만 원, 어떤 줄은 원)

### 직책 호칭
- 공공: 사무관/주무관/팀장/과장/국장/실장
- 대기업: 대리/과장/차장/부장/임원/대표
- 호칭 잘못 쓰면 즉시 비전문가로 인식됨

## 🎯 영업 단계별 핵심 메시지 프레임

| 단계 | 핵심 질문 | 답해야 할 것 |
|---|---|---|
| Cold | "이 회사 뭐 하는 곳?" | 30초 안에 회사 정체성 |
| Warm | "왜 우리한테 영업해?" | 우리 기관에 맞는 이유 |
| Hot | "어떻게 할 거야?" | 구체적 방법론 + 일정 |
| Decision | "내가 책임지면 위험 없나?" | 위험 관리 + 유사 사례 |
| Bidding | "RFP 요구를 다 충족하나?" | 일대일 매핑 + 추가 가치 |

## 🚨 자주 하는 실수

| ❌ 미국식 영업 사고 | ✅ 한국 공공·B2B 사고 |
|---|---|
| "ROI 350%" 같은 수치 강조 | "유사 ○○청 도입, 효과 확인" 사례 강조 |
| 영문 약어 남발 (SaaS, B2B, KPI) | 한글 풀어쓰기 (서비스형 소프트웨어 등) |
| 가격을 일찍 공개 | 가치 합의 후 견적 단계에서 제시 |
| 화려한 시각적 디자인 | 보수적·정돈된 디자인 (민주당 PI 스타일도 OK) |
| 빠른 의사결정 압박 | 절차·관계 존중하며 기다림 |
| 영문 회사 소개서 그대로 번역 | 한국 맥락 사례로 전면 재작성 |

## 🔗 연계 스킬

이 스킬은 다음 스킬과 함께 쓰면 시너지가 큽니다:
- **`gov-proposal`**: 공공 제안서 본문 작성 (이미 보유)
- **`gov-proposal-training`**: 공무원 대상 AI 교육 제안 (이미 보유)
- **`press-release`**: 사업 추진 후 홍보 보도자료 (이미 보유)
- **`sky-pptx-workflow`**: 영업용 PPT 자동 생성 (이미 보유)

## 🎓 강의 시연 포인트

**AI 교육 강의에서의 활용**:

1. **"공공기관 영업 30분 데모"**: 학습자가 자기 회사 + 타깃 기관 입력 → 5단계 영업 자료 자동 생성 시연
2. **RFP 분석 워크샵**: 실제 나라장터 RFP 1건 → AI가 평가표 기반 응답 초안 작성
3. **임원 보고 요약 실습**: 30장 제안서 → 3장 임원 요약 자동 변환
