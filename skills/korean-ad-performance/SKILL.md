# Korean Ad Performance Skill

> **2026 한국 광고 시장**: 디지털 광고 약 8조 원 / 네이버·카카오·메타가 70% 이상 점유
> 한국 광고는 **플랫폼별 특성, 한국인 클릭 패턴, 정서가 글로벌과 다릅니다**.

## 🔑 플랫폼별 핵심 특성

### 1. 네이버 광고 (GFA + 검색광고)

**네이버 검색광고**:
- **장점**: 구매 의도 높은 트래픽 (검색 = 능동적 의도)
- **단점**: 단가 상승, 경쟁 키워드 클릭당 5천~수만 원
- **적합**: B2B, 고관여 상품, 지역 비즈니스
- **핵심 KPI**: 검색 노출수 → 클릭률 → 전환율

**네이버 GFA (Group For Advertising)**:
- 디스플레이·동영상 광고
- **장점**: 한국인 80%+ 도달 가능
- **단점**: 인텐트가 약함, 인지도 캠페인 위주
- **적합**: 브랜드 인지, 신제품 출시
- **핵심 KPI**: 노출수 → 도달 → 동영상 시청 완료율

### 2. 카카오모먼트

- **타겟팅 강점**: 카카오톡 친구 기반·관심사 타겟팅 (한국 1위)
- **광고 위치**: 카톡 비즈보드, 카카오스토리, 다음, 카카오뷰
- **적합**: 카톡 친구추가 캠페인, 카카오 채널 구독자 모집
- **핵심 KPI**: 친구추가 단가 (CPF), 채널 진입률

### 3. 메타 (인스타 + 페북) 한국

- **글로벌 동일**: 광고 시스템 기본은 동일
- **한국 특이점**:
  - 한국어 카피·이미지 별도 제작 필수 (영문 자동 번역 절대 금기)
  - 인스타 의존도가 페북보다 훨씬 높음 (한국 페북 사용자 감소)
  - 릴스 광고 효율이 피드 광고보다 평균 30% 이상 좋음
- **적합**: 20~40대 B2C, 라이프스타일 브랜드

### 4. 구글 한국

- **검색광고**: 네이버 대비 점유율 낮지만 단가도 낮음 (보완재)
- **유튜브 광고**: 한국에서 가장 영향력 큰 영상 광고 채널
- **GDN (디스플레이)**: 효율 보통, 리타겟팅 위주
- **적합**: 영문권 동시 캠페인, 유튜브 영상 광고

## 🛠️ 작업 프로세스

### Step 1: 광고 목표 진단

사용자에게 질문:

```
"광고 캠페인의 1차 목표는?"
1. 브랜드 인지도 확보 → 도달·노출 최적화
2. 트래픽 유입 → 클릭률 최적화
3. 리드 수집 → 전환 최적화
4. 매출 직접 발생 → ROAS 최적화
5. 리타겟팅·재구매 → 빈도·LTV 최적화

"예상 월 광고 예산은?"
1. 100만 원 미만 → 채널 1개 집중
2. 100~500만 원 → 채널 2~3개 + A/B 테스트
3. 500~3000만 원 → 채널 4개 + 풀퍼널
4. 3000만 원 이상 → 통합 미디어 믹스 전략
```

### Step 2: 매체 믹스 추천

| 비즈니스 유형 | 예산 비중 (월 500만 원 기준 예시) |
|---|---|
| B2B 서비스·SaaS | 네이버 검색 50% / GFA 20% / 구글 검색 20% / 메타 10% |
| B2C 라이프스타일 | 메타 50% / 카카오모먼트 25% / GFA 15% / 유튜브 10% |
| 지역 서비스 (음식점·학원) | 네이버 플레이스 40% / 카카오모먼트 30% / 네이버 검색 30% |
| 교육·강의 | 네이버 검색 35% / 메타 30% / 카카오 20% / 유튜브 15% |
| 이커머스 | 네이버 쇼핑 40% / 메타 30% / 카카오 20% / 구글 쇼핑 10% |
| 공공·정책 홍보 | GFA 40% / 유튜브 30% / 메타 20% / 카카오 10% |

### Step 3: 한국형 광고 소재 5요소

한국 광고 소재가 잘 되려면 다음 5가지가 갖춰져야 합니다:

1. **첫 3초/첫 한 줄 후킹** — 한국인은 스크롤 속도가 빠름
2. **구체적 숫자** — "30% 절감"이 "효과적"보다 5배 강력
3. **사회적 증거** — "○○명이 선택", "○○ 기업 사용중"
4. **이질감 회피** — 영문 카피·외국인 모델은 거부감 유발 (B2C)
5. **명확한 CTA 한 줄** — "지금 신청하기", "무료 진단 받기"

### Step 4: A/B 테스트 설계

광고 시작 시 **반드시 3종 이상 소재로 동시 출고**:

```
소재 A: 후킹형 (호기심 자극 헤드라인)
소재 B: 혜택형 (구체적 숫자·할인 강조)
소재 C: 사례형 (실제 후기·고객사 사례)
```

7~14일 후 효율 최저 소재 폐기, 최고 소재 변형 추가.

## 📝 한국형 광고 카피 공식

### 헤드라인 템플릿 (검증됨)

```
[숫자] + [기간/대상] + [결과]
예: "월 300만 원 버는 N잡러 7가지 비밀"

[부정 어휘] + [전환]
예: "ChatGPT만 쓰면 안 되는 이유"

[권위] + [추천]
예: "한국은행 임원도 쓰는 AI 활용법"

[질문] + [공감]
예: "혹시 AI 교육비만 쓰고 안 늘었나요?"

[비교] + [선택지]
예: "Claude vs ChatGPT, 업무에 뭐가 나을까"
```

### 본문 카피 5단 구조

```
1. 후킹 (1줄)
   → 첫 인상으로 멈추게 한다

2. 공감·문제제기 (2~3줄)
   → "이런 경험 있으셨죠?"

3. 솔루션·차별점 (2~3줄)
   → "그래서 우리가 ○○을 만들었습니다"

4. 사회적 증거 (1~2줄)
   → "이미 ○○명이, ○○ 기업이 도입"

5. CTA (1줄)
   → "지금 30초 안에 신청"
```

## 📊 한국 광고 KPI 벤치마크

| 업종 | CTR (클릭률) | CVR (전환율) | CPC (클릭당단가) |
|---|---|---|---|
| 교육 (네이버 검색) | 2~5% | 3~7% | 3,000~8,000원 |
| B2B (네이버 검색) | 1~3% | 1~3% | 5,000~30,000원 |
| 이커머스 (메타) | 1~2% | 1~3% | 300~800원 |
| 라이프스타일 (인스타 릴스) | 2~5% | 0.5~2% | 200~600원 |
| 카카오모먼트 (CPC) | 0.5~1.5% | 0.5~2% | 300~700원 |
| 유튜브 인스트림 | - (CPV) | - | 30~150원/시청 |

> 위 수치는 평균 벤치마크. 업종·시즌·소재 품질에 따라 ±50% 변동 정상.

## 🚨 자주 하는 실수

| ❌ 잘못된 접근 | ✅ 올바른 접근 |
|---|---|
| 메타 광고 카피를 네이버에 그대로 사용 | 플랫폼별 톤·길이 재제작 |
| 외국 모델·영문 카피 그대로 사용 (B2C) | 한국인 정서·언어로 현지화 |
| 1개 소재로만 광고 시작 | 최소 3개 소재 A/B 테스트 |
| 노출만 보고 CTR 무시 | CTR < 0.5%면 즉시 소재 교체 |
| ROAS 한 달 안에 판단 | 최소 2주 안정화 + 1개월 학습 후 판단 |
| 광고 단가만 보고 매체 선택 | 전환율·고객 단가까지 종합 판단 |
