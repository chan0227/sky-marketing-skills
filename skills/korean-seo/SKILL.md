# Korean SEO Skill

> **한국 검색 시장 점유율 (2026년 기준)**: 네이버 ~58%, 구글 ~32%, 다음 ~6%, 빙/기타 ~4%
> 한국 SEO는 구글 SEO와 **알고리즘 자체가 다릅니다**. 영어권 SEO 지식을 그대로 적용하면 실패합니다.

## 🎯 언제 이 스킬을 쓰나요?

다음 요청이 들어오면 즉시 이 스킬을 활성화합니다:

- "네이버 상위노출 시켜줘"
- "블로그 검색 잘 되게 써줘"

- "한국에서 검색 잘 되는 콘텐츠"

## 🔑 핵심 원칙

### 1. 네이버는 "검색엔진"이 아니라 "포털"이다

네이버 검색 결과는 **VIEW(블로그·카페), 지식iN, 쇼핑, 플레이스, 동영상, 뉴스** 등 섹션별로 노출됩니다. 키워드마다 어떤 섹션이 상위에 뜨는지 먼저 파악해야 합니다.

**작업 순서**:
1. 타깃 키워드를 네이버에 직접 검색 → 어떤 섹션이 상단에 뜨는지 확인
2. 그 섹션에 맞는 콘텐츠 포맷 결정 (블로그 글? 카페 후기? 지식iN 답변?)
3. 해당 포맷에 맞는 알고리즘 최적화 적용

### 2. C-Rank와 D.I.A.를 이해해라

- **C-Rank**: 블로그·카페 **출처(채널)의 신뢰도**를 평가
  - 한 분야를 꾸준히 다룬 블로그 = 가산점
  - 잡다한 주제를 다 다루는 블로그 = 감점
- **D.I.A. (Deep Intent Analysis)**: 개별 **문서의 품질**을 평가
  - 체험·경험 기반 글 = 가산점
  - 광고성·복붙성 글 = 감점
- **D.I.A.+ (2023~)**: 사용자 의도와 문서의 적합성을 딥러닝으로 분석

**실전 적용**:
- 블로그 운영 시: **한 주제 카테고리로 30개 이상 누적**되면 C-Rank가 오르기 시작
- 글 작성 시: **개인 경험, 사진, 구체적 수치**가 들어가야 D.I.A. 점수가 오름

### 3. 키워드 전략: "롱테일 + 지역명 + 비교어"

한국 검색자는 다음 패턴을 자주 씁니다:
- `[지역명] + [업종] + 추천` (예: "천안 AI 교육 추천")
- `[제품/서비스] + 후기` (예: "노션 AI 후기")
- `[A] vs [B] 차이` (예: "ChatGPT vs Claude 차이")
- `[키워드] + 가격 / 비용 / 견적`

영어권 SEO처럼 단일 키워드를 노리지 말고, **3~5단어 롱테일 키워드 50개**를 잡는 게 효과적입니다.

## 🛠️ 작업 프로세스

사용자가 콘텐츠 작성을 요청하면 다음 순서로 진행합니다:

### Step 1: 키워드 인텔리전스

```
1. 네이버 검색광고 시스템(searchad.naver.com)의 키워드 도구 활용 권장
2. 월 검색량 100~5000인 롱테일 키워드 선정 (경쟁 적고 전환 높음)
3. 자동완성·연관검색어로 의도 파악
4. 모바일/PC 검색 비율 확인 (한국은 모바일 75% 이상)
```

### Step 2: 채널 선택

| 키워드 유형 | 추천 채널 | 이유 |
|---|---|---|
| 정보 탐색형 ("~ 방법", "~ 하는법") | 네이버 블로그 | VIEW 섹션 상위 노출 가능 |
| 비교·검토형 ("~ vs", "~ 후기") | 블로그 + 지식iN | 양쪽 모두 노출 시도 |
| 지역 기반 ("천안 ~") | 네이버 플레이스 + 블로그 | 지도 검색 연계 |
| 전문 지식형 ("~ 원리", "~ 분석") | 티스토리 + 브런치 | 구글 검색에서도 강함 |
| 트렌드·신상 | 인스타 + 블로그 | 빠른 휘발성 콘텐츠 |

### Step 3: 콘텐츠 구조 설계

**네이버 블로그 최적화 구조**:
```
[제목] 키워드를 앞쪽 25자 이내에 배치
[썸네일] 직접 촬영 사진 1장 이상 (외부 이미지는 감점)
[본문 도입] 첫 문단 300자 내에 키워드 2~3회 자연스럽게 배치
[본문 중반] 소제목 3~5개로 구조화 (H2 태그)
[본문 후반] 개인 경험·후기·인사이트 (체험 키워드)
[해시태그] 정확히 30개 (네이버 한도)
[지도/링크] 지역 기반이면 플레이스 연동
```

### Step 4: 작성 후 체크리스트

- [ ] 키워드가 제목 + 첫 문단 + 마지막 문단에 모두 등장하는가?
- [ ] 직접 촬영한 사진이 5장 이상인가? (스크린샷도 OK)
- [ ] 본문이 1500자 이상인가? (D.I.A. 권장)
- [ ] 외부 링크는 본문 한참 뒤로 빼거나 최소화했는가?
- [ ] 광고성 문구("최저가", "이벤트", "지금 구매") 과다하지 않은가?
- [ ] 같은 블로그의 다른 글로 내부 링크 1~2개 연결했는가?

## 📱 채널별 세부 전략

### 네이버 블로그
- **발행 시간**: 평일 오전 8~10시, 오후 7~10시 (체류시간↑)
- **공감/댓글**: 자연스러운 댓글 3~5개가 알고리즘에 유리
- **이웃 활동**: 같은 주제 블로거 30명 이상 이웃 추가
- **금기**: 동일 글 복붙, 외부 URL 도배, 광고 키워드 남발

### 네이버 카페
- **운영형**: 직접 카페 만들기 (시간 오래 걸리지만 자산이 큼)
- **참여형**: 기존 카페 등업 후 자연스러운 정보 글 작성
- **금기**: 노골적 광고, 외부 링크 (대부분 카페 규정 위반)

### 지식iN
- **답변 전략**: "전문가" 등급 달성이 핵심 (의사·변호사·세무사 인증)
- **링크 전략**: 답변 끝에 출처로 자기 블로그 링크 (자연스럽게)
- **금기**: 광고성 답변, 동일 답변 복붙

### 카카오 다음 검색
- **티스토리 우선 노출**: 카카오 계열이라 SEO에 유리
- **카카오뷰**: 콘텐츠 큐레이션 채널 운영 가능
- **트렌드**: 다음의 점유율이 낮아 우선순위는 낮춤

### 구글 (한국에서)
- **티스토리 / 브런치**: 구글이 잘 색인
- **WordPress 자체 도메인**: 가장 강력하지만 진입장벽
- **네이버 블로그는 구글에 약함**: 구글 노출 원하면 다른 채널 필수
